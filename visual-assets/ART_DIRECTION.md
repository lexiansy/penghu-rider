# 澎湖騎士 visual system

The Phase 2 art set follows one system: flat hand-drawn 2D shapes, bold charcoal-green ink, subtle risograph halftone and printed-paper grain, and a restrained Penghu coastal palette. The silhouettes are intentionally heavier than editorial illustration so they survive iPhone-scale rendering.

Palette anchors: seafoam `#dceee9`, deep teal `#0c5c66`, sand `#f5efe2`, ochre `#d89a55`, restrained coral `#b85f4e`, charcoal green `#15373c`.

The map carries the narrative hierarchy. Standalone landmark art is reserved for stage introductions and compact map emphasis. The scooter/Hono token is the only moving map character. Monster Book art is categorical—not per question—and maps to real source subcategories. Official question content remains undecorated.

Generated with the built-in image generation tool. The final prompt family required: no embedded text, no photorealism, no 3D, no corporate-vector styling, clear mobile silhouettes, and consistent printed coastal texture. Source generations are retained in `visual-assets/source/`; mobile outputs are prepared by `scripts/process_game_art.py`.
